Sobre o curso

O curso técnico em Desenvolvimento de Sistemas prepara os estudantes para criar, testar e manter soluções digitais para diferentes necessidades.

O que você aprenderá

  • Lógica de programação e algoritmos
  • Desenvolvimento de sites com HTML, CSS e JavaScript
  • Programação orientada a objetos
  • Banco de dados e SQL
  • Desenvolvimento e consumo de APIs
  • Controle de versões com Git e GitHub

Áreas de atuação

O profissional pode atuar como desenvolvedor web, desenvolvedor mobile, auxiliar em projetos de software ou analista de sistemas júnior.

Perfil do estudante

É importante gostar de tecnologia, resolver problemas e trabalhar em equipe. Curiosidade, organização e aprendizado contínuo também são essenciais.
